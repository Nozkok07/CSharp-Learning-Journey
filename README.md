# C# Learning Journey 🚀

C# ve .NET öğrenme sürecimde geliştirdiğim konsol uygulamalarını, algoritma pratiklerini ve nesne yönelimli programlama (OOP) çalışmalarımı içeren ana repo.

---

### 📂 Projeler ve İçerikler

| Proje Adı | Açıklama / Kapsanan Konular |
| :--- | :--- |
| **RPG_KarakterArenaSimulasyonu** | OOP prensipleri (Kalıtım, Polimorfizm), dövüş ve sıra tabanlı mantık simülasyonu. |
| **GuvenliBankaHesabiYonetimi** | Kapsülleme (Encapsulation), bakiye kontrolü ve temel güvenlik/doğrulama mantığı. |
| **GelismisATM** | Menü navigasyonu, kullanıcı doğrulama ve işlem geçmişi simülasyonu. |
| **GucluSifreUreticiVeAnalizoru** | String manipülasyonu, regex/karakter kontrolleri ve rastgele veri üretimi. |
| **GunlukGelirHarcamaButcesiTakipcisi** | Veri yapıları, gelir/gider hesaplama algoritmaları ve bütçe raporlama. |
| **Ogrenci_not_ve_istatislik** | Diziler, koleksiyonlar ve ortalama/istatistik hesaplama algoritmaları. |
| **AdamAsmaca** | String/Char işlemleri, döngüler ve oyun durumu yönetimi. |
| **HesapMakinesi** | Temel aritmetik operatörler, koşullu ifadeler ve kullanıcı girdisi ayrıştırma. |
