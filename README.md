# C# & .NET Learning Journey 🚀

A structured and comprehensive repository documenting my hands-on progression in **C#** and **Object-Oriented Programming (OOP)**. This monorepo contains modular console simulations, financial modeling tools, interactive games, and algorithm practices built on modern .NET architecture.

---

### 📂 Projects & Overview

| Project Name | Description & Technical Focus |
| :--- | :--- |
| **BorsaVeHalkaArzSistemi** | Financial market simulation modeling IPOs, lot distributions, and sectoral stocks (Energy, Steel). Employs OOP Inheritance (`base`), Polymorphism (`override`), `decimal` precision for exact calculations, and simulated government tender/news shock algorithms. |
| **PapaganBakimAsistani** | Care and health tracking assistant featuring OOP encapsulation, parameterized constructors, routine task lists, and robust input validation. |
| **RPG_KarakterArenaSimulasyonu** | Turn-based RPG combat simulation emphasizing OOP principles, inter-object interactions, dynamic state updates, and encapsulated character stats. |
| **MiniFootbolsimulator** | Match simulation engine combining probability/randomness algorithms, game state tracking, and modular OOP design. |
| **GuvenliBankaHesabiYonetimi** | Banking core focusing on data integrity, encapsulation, balance validation, and secure transaction workflows. |
| **GelismisATM** | Interactive ATM menu system simulating multi-account navigation, user authentication, and persistent transaction history. |
| **GucluSifreUreticiVeAnalizoru** | Security utility leveraging string manipulation, regex-based strength scoring, and randomized credential generation. |
| **GunlukGelirHarcamaButcesiTakipcisi** | Budget tracking and reporting tool utilizing structured collections, expense categorization, and net balance calculation algorithms. |
| **Ogrenci_Not_Ve_istatistik** | Academic grading and statistical engine implementing arrays, generic collections, and aggregation algorithms. |
| **AdamAsmaca** | Word-guessing game highlighting character/string manipulation, loop mechanics, and interactive game loop state control. |
| **HesapMakinesi** | Arithmetic engine with input parsing, error handling, and structured conditional execution. |
